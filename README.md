# SETI Post-Detection Protocols archive

A public archive of the International Academy of Astronautics (IAA) SETI post-detection protocols, from the 1989 Declaration of Principles to the 2026 Update, with summaries of each document and the IAA SETI Committee records of how the protocols were developed.

The site is a single static page (`index.html`) plus the documents in `files/`. It needs no server, database or build service, and works on GitHub Pages or any other web host.

## Contents

| Path | What it is |
|---|---|
| `index.html` | The website. Generated by `build.py`; do not edit by hand. |
| `files/` | The documents, renamed as `YYYY-MM-short-name.pdf`. |
| `catalogue.json` | One entry per document: date, title, status, summary, notes, file name. |
| `principles.json` | The text of each principle in the 1989, 2010 and 2026 declarations. |
| `compare.json` | How the principles are grouped on the "Compare the texts" section. |
| `milestones.json` | The timeline of the 2017–2026 revision. |
| `build.py` | Regenerates `index.html` from the JSON files. Needs Python 3 only. |

## Adding or changing a document

1. Put the file in `files/`, named `YYYY-MM-short-name.pdf`.
2. Add an entry to `catalogue.json`, copying the shape of an existing one. Set `"release": "public"`.
   `category` is one of `core`, `revision`, `scales`, `history`, `governance`, `meetings`.
   Meeting records also need a `meeting` label, for example `"IAC 2026, Antalya"`.
3. Run `python3 build.py`.
4. Commit and push. GitHub Pages republishes within a minute or two.

Use `"release": "cite"` with an empty `"file"` for a document that should be listed but not hosted, for example because of publisher copyright, or `"release": "link"` with a `"link"` URL for a document hosted elsewhere.

## Publishing with GitHub Pages

In the repository on GitHub: Settings → Pages → Build and deployment → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)`. The `.nojekyll` file tells GitHub to serve the files as they are.
